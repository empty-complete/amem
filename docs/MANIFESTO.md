# amem manifesto

[Манифест на русском](MANIFESTO.ru.md)

Knowledge is a meme — a unit that lives, copies itself and can be checked.

People and AI agents are becoming one environment. In it, knowledge has to
outlive sessions, context windows and individual carriers — both human and
artificial. amem is the shared memory of this environment.

We believe that:

- **Every claim deserves a source.** Not because sources are always right,
  but because without one a claim cannot even be questioned properly.
- **Nothing is erased.** A mistake is not deleted, it is superseded — with
  a revision, a reason and a name. Memory with a history can be trusted more
  than memory that was always «right».
- **Checking is a habit, not a feature.** A quote is verified against the file.
  A value carries its unit. A code comes from a known vocabulary. Small,
  boring checks, every time.
- **The human decides.** Agents may propose, collect and pre-verify. Accepting
  a claim into the canon is a human decision, and the system keeps it visible
  who made it.
- **Memory should be portable.** Your knowledge is yours: open formats,
  plain PostgreSQL, files by content hash. A base can be forked from a hub
  into a project, and its atoms remember where they came from.

amem is built in the open, calmly and without promises of a new life.
It is a tool for remembering well.
