# amemo — подпроект 5, часть F «Подборки»: план и итог

**Goal:** Обмен частями базы. Экспорт с отбором («с файлами», «с пакетами и моими видами»), готовый отбор «Антология: проверенное и предпочтительное» с читаемым HTML-отчётом. Импорт по шагам: файл → проверка (`inspect`) → пробный импорт с отчётом → «Влить в базу».

**Спецификация:** разд. 5.10 («Подборки»), разд. 10 (часть F).

## Задачи

- [x] **F1. `amemo/anthology.py`** (ядро):
  - `select` — действующие `verified`, без `rank: deprecated`; если у одной величины одного объекта есть `preferred`, остаются только `preferred`;
  - `report` — самодостаточная HTML-страница: записи по объектам, значения, суть, источники с местом и цитатой, всё экранировано;
  - `export` — `bundle.export` по отобранным ссылкам и отчёт.
  - Тесты `tests/test_anthology.py` на PostgreSQL 18 и 16.
- [x] **F2. Контракт:** у `POST /bundles/export` — `with_packs` («Мои виды» едут с подборкой; в библиотеке уже есть `bundle.export(with_packs=True)`) и `title` для отчёта антологии. Остальные пути подборок — без изменений (реализует служба).
- [x] **F3. Экран «Подборки»** (`/bundles`):
  - экспорт с отбором (теги, проект, виды, классы, статусы, с даты), файлами, пакетами и антологией; итог — ссылка на zip и отчёт;
  - импорт по шагам со способом принять статусы («сохранить» или «всё на проверку»), отчётом пробного импорта (новые, без изменений, изменённые, в очередь, предупреждения, совпадения ключей) и ссылкой на пункты импорта в проверке.
- [x] **F4. Моки** (`handlers-f.ts`, `bundle-sample.zip`) и **e2e** (антология и отчёт; импорт с пробным прогоном; повреждённая подборка); axe на `/bundles`.

## Отличия от исходного плана

Конфиг человека (папки, виды) отдельной частью `ui` подборки не делался: папки уже едут полем `scope.folder` записей, «Мои виды» — пакетом (`with_packs`). Отдельная часть `ui` понадобится, когда появятся настраиваемые виджеты экранов (часть G или позже).
