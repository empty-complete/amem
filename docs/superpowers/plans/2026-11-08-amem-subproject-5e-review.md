# amem — подпроект 5, часть E «Проверка»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Очередь проверки, в которой человек решает быстро и уверенно.

- **Две панели:** список пунктов слева, пункт справа. В пункте — утверждение с источником (тот же вид, что на записи), замечания проверки и то, о чём именно спрошено: сравнение ревизий для правки, старая и новая версия фрагмента для «источник изменился», вердикт модели для «сомнения модели».
- **Решение** одним нажатием или клавишей (`Y`, `N`, `S`, `J`/`K`), с окном отмены 6 с и `keepalive`; «Уже решено» — словами.
- **Счётчик** в верхней строке.
- **«База»** — статистика очереди, статусы, сверка, пакеты, бэкапы.

**Architecture:** фича `web/src/features/review/`:

| Модуль | Что делает |
|---|---|
| `diff.ts` | Пословное сравнение ревизий по полям |
| `reasons.ts` | Причина → вопрос словами и значок |
| `ReviewPage.tsx` | Две панели, адрес — `/review/$itemId?reason=&state=` |
| `QueueList.tsx` | Виртуальный список, TanStack Virtual |
| `ReviewItem.tsx` | Пункт: утверждение, источник, замечания, сравнение, вердикт |
| `DecisionBar.tsx` | Заметка и кнопки решения |
| `useDecision.ts` | Решение через очередь с окном отмены части D (`enqueue` с `run`) |

«База» — `features/base/BasePage.tsx`. Утверждение и источник берутся из части B (`Properties`, `Body`, `SourcePanel`), окно неба — из части C.

**Спецификация:** `docs/superpowers/specs/2026-11-06-amem-subproject-5-web-ui-design.md`, разд. 5.7, 5.10 (База), 5.13. **Эскиз:** `v2-mail` («Почта в три панели»).

**Контракт.** `/review/*` и `/base`, `/backups` реализует служба (часть 4a). По её сообщению от 07.11:
- `resolve.outcome` — `confirmed | refuted | partial | uncertain`; человеку `partial` недоступен; пропуск — только в UI, без запроса;
- 409 — «уже решено» с тем, кто и когда;
- `ReviewItemView`: для `edit` и `imported` есть `current` и `proposed` (с `changes`), для `source_changed` — `versions`;
- `ReviewStats`: `queue`, `done`, `records`, `verdicts`, `now`, `days`, `changesets`, `audit`.

Веб в контракт этой частью не пишет; моки повторяют эту форму. Если 4a сольётся раньше — типы пересобираются, правки только в моках.

**Ветка:** `subproject-5e-review` от `main`. Worktree: `~/projects/amem-web-e`.
