# amemo — подпроект 5, часть L «Веб на законченной службе»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** веб работает с законченной службой (подпроект 4 закрыт, часть 4d — PR #45): шаблоны видов, «Мои виды», загрузка файлов, задачи и вход в общую службу по токену. Моки повторяют форму ядра, а не придуманную до 4d.

**Откуда задача.** Сверка веба с ядром `main` (`amemo/forms.py`, контракт v1):

| Что | Ядро | Веб и моки сейчас |
|---|---|---|
| значение параметра | `content.values`, `key: value`, тип `quantity` | мок: `content.values[0]` |
| величина из `ui.fields` | путь `content.values[property=X]`, `key` — код величины | мок: `key: value` |
| поля сущности | `codes` всегда; `part_of` — не поле, а связь | мок: поле `part_of` (ушло бы в тело и не прошло схему), `codes` не у всех |
| период | при `valid_from` и `valid_to` — одно поле `key: valid`, `type: period`; без пары — свой путь | совпадает |
| общая служба (`AMEMO_TOKENS`) | статика `/ui` открыта, API — только `Authorization: Bearer`; cookie нет | токена нигде нет: на общей службе интерфейс получает 401 на всё |
| новые ответы | 408 `body_timeout`, 503 `timeout` (`/graph` > 15 с), 507 `quota_exceeded` | заголовка словами нет |
| e2e против службы | `/templates` отдаётся | в e2e осталось временное исключение для его 404; записи по шаблону, «Моих видов» и загрузки файла не проверяют |

**Спецификация:** `docs/superpowers/specs/2026-11-06-amem-subproject-5-web-ui-design.md`, разд. 5.9, 5.12, 6; служба — спецификация подпроекта 4, разд. 3 (вход), 6a (формы, «Мои виды»).

**Ветка:** `subproject-5l-service` от `main`. Проверки — в CI, локально не гонять. Автослияние включать, когда `web` и `web-service` уже зелёные: это необязательные проверки, и автослияние их не ждёт.

### Task 1: Моки шаблонов по форме ядра
**Files:** `web/src/mocks/fixtures/templates.json`, тесты записи, где проверяются пути.
- [ ] `parameter`:
  - значение — `content.values`, `key: value`;
  - период — `key: valid`, `type: period`.
- [ ] `sensor_reading`: величина — `content.values[property=relative_humidity]` с `key: relative_humidity`.
- [ ] Сущности: поле `codes` у каждой, `part_of` убрать. «Часть чего» задаётся связью: виджет «Связи», `LinkProposal` `part_of`.
- [ ] Unit-тест: тело записи из формы мока проходит `toProposal` без чужих полей. Нет `part_of` в теле, значение лежит в `content.values` с кодом величины.

### Task 2: Вход в общую службу по токену
**Files:** `web/src/api/auth.ts` (новый), `web/src/api/client.ts`, `web/src/features/write/submitQueue.ts`, прочие прямые `fetch` к `/api/v1`, `web/src/app/shell/SignIn.tsx` (новый), `web/src/routes/__root.tsx`, i18n.
- [ ] **Токен в запросах:**
  - `auth.ts` хранит токен: на вкладку — `sessionStorage`, с «Запомнить на этом устройстве» — `localStorage`;
  - `authHeaders()` подставляет `Authorization: Bearer` во все запросы к API: `openapi-fetch`, очередь записи с `keepalive`, загрузки;
  - сам токен в адрес и журналы не попадает.
- [ ] **Экран входа:**
  - на ответ 401 службы показывает поле токена с объяснением «Служба общая: нужен токен, его выдаёт владелец (`amemo token create`)»;
  - после ввода — повтор запросов;
  - «Выйти» в настройках стирает токен.
- [ ] **Только чтение:** токен без права записи даёт 403 на запись. Интерфейс пишет «Токен только для чтения», а кнопки записи не прячет.
- [ ] **Локальная служба (cookie) не меняется:** токена нет — заголовка нет.
- [ ] **Тесты:** unit для `auth.ts` и клиента; e2e против службы в режиме `AMEMO_TOKENS` — отдельный проект Playwright с файлом токенов, вход, чтение и запись, неверный токен.

### Task 3: Новые ответы словами
**Files:** `web/src/api/errors.ts`, i18n.
- [ ] Заголовки по статусу и коду:
  - 408 — «Служба не дождалась тела запроса»;
  - 503 `timeout` — «Служба не уложилась в 15 с — сузьте глубину или выбор»;
  - 507 `quota_exceeded` — «Место под подборки и загрузки исчерпано».

  У прочих кодов (`template_exists`, `template_in_use`, `object_path_taken`, `task_closed`) служба уже отдаёт текст в `detail`, его и показываем.

## Риски

| Риск | Что делаем |
|---|---|
| Токен в `localStorage` доступен скрипту страницы | По умолчанию — `sessionStorage`; `localStorage` только по явному «Запомнить»; строгая CSP службы (`script-src 'self'`) |
| Пропущенный прямой `fetch` без заголовка | Один `authHeaders()`; тест-перечень мест, где `fetch` идёт к `/api/v1`, все через него |
| Форма ядра снова уйдёт от моков | Сверка моков с контрактом во время тестов уже есть; e2e против службы проверяет запись по настоящей форме |
