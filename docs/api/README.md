# HTTP-контракт amem v1

`http-v1.openapi.yaml` — контракт между службой amem (подпроект 4) и веб-интерфейсом (подпроект 5, `web/`).
Спецификация — `docs/superpowers/specs/2026-11-06-amem-subproject-5-web-ui-design.md`, разд. 6.

- **Реализует** служба: отдаёт контракт по `/api/v1/openapi.json`, её тесты сверяют ответы со схемами.
- **Потребляет** веб-UI: типы генерируются из файла (`cd web && npm run api:types`), CI проверяет свежесть (`npm run api:check`), фикстуры моков проверяются схемами (`web/tests/contract.test.ts`).
- **Менять** — только правкой этого файла в PR, который проходит обе стороны. Линтер: `npx @redocly/cli lint docs/api/http-v1.openapi.yaml --config docs/api/redocly.yaml`.
- **Ошибки** — `application/problem+json` (RFC 9457): `type`, `title`, `status`, `detail`, `code`; отказ проверки — ещё `issues` (`CheckIssue`). 401 — нужен вход, 403 — только чтение, 409 — пункт уже решён, 422 — отказ проверки, 503 — база недоступна.
- **Агент записи** служба берёт из сессии (`person:…`); UI его не передаёт.
- **Вход** — `Authorization: Bearer`, только если служба его потребовала; локальная служба работает без входа.

## Изменения

- **Часть B веб-интерфейса (чтение).** `ObjectView.cited_by` — массив `ObjectCitation` (запись, версия, место, цитата, итог сверки) вместо подписей; у `ObjectView` — `pages` (из кэша текста, `null`, пока текст не извлекался) и `sheets` (только xlsx/xlsm); путь `GET /objects/{id}/versions/{n}/sheet` (ячейки листа, не больше 10 000, иначе 413); у `RecordView` — `about` и `ancestors` с подписями; фильтр `about` у `GET /records`.
- **Часть C веб-интерфейса (небо).** `GET /graph`: `ref` не обязателен (без него — обзор базы, `recipes.overview`), параметры `limit` (1–1000, по умолчанию 300; и для окрестности) и `project`; `GraphResult.ref` может быть `null`, новое обязательное `total`; у `GraphNode` обязательные `pending` и `degree`.
- **Часть D веб-интерфейса (запись человека).** `GET /templates` (`TemplateView` с формой `FormField[]`, телом и виджетами), `PUT/DELETE /packs/mine/templates/{code}` («Мои виды», `TemplateDraft`), `GET/POST /objects` (поиск и загрузка файла), `GET/POST /tasks` (задачи агентам). `/submit` (`Proposal`, `LinkProposal`) и папки вносит служба (часть 4a).
- **Часть F веб-интерфейса (подборки).** У `POST /bundles/export` — `with_packs` (пакеты, в том числе «Мои виды», едут с подборкой; в библиотеке — `bundle.export(with_packs=True)`) и `title` для отчёта антологии (`amem.anthology.export`).
- **Часть 4a службы (папки, `null`, массивы).** Пути записи папок: `POST /folders` (201 `Folder`, 409 `folder_exists`, 422 `folder_invalid`), `DELETE /folders/{path}` (204; непустая — 409 `folder_not_empty`), `PATCH /folders/{path}` (`FolderRenamed`); `{path}` — путь целиком в `encodeURIComponent`. `ChangeEvent.type` — ещё `folder` с `from`/`to`; `changes` — массив отличий (`path`, `before`, `after`). Могут быть `null`: `Session.base_name`, `Base.name`, `SearchHit.matches[].source_rank`, `SourceView.verdict`, `ObjectVersionView.digest` и `size` (сайт, переписка), `Backup.created_at`; `ObjectView.original_name` необязателен (страница сайта). `Imported.warnings` и `collisions` — массивы строк. `SearchResult.embedding_coverage` — доля (0–1). У `VocabEntry` описаны `definition` и `family`. Копия контракта — в пакете службы (`amem/service/http-v1.openapi.yaml`): тест службы сверяет её с этим файлом байт в байт, поэтому правка здесь — вместе с `cp docs/api/http-v1.openapi.yaml amem/service/`. Описаны поля, которые служба уже отдаёт: времена и `reason` у `ChangeEvent`, `agent` и `created_at` у `LinkView`, `claimed_until` у `ReviewItem`, `retrieved_at` и `format_puid` у `ObjectView`, `page`, `anchor`, `edition`, `checked_at` у `SourceView`, `rule`, `when` и `rank` у `CardField`; служебные хэши тела наружу не уходят. Тест службы сверяет ответы строго — поле вне контракта — расхождение; `Problem` открыт для расширений RFC 9457. Ошибки: 416 `range_not_satisfiable` у файла версии, 503 `store_unavailable` — не подключено хранилище копий; у `/search` и `/similar` по тексту отказ модели — не 503, а `semantic: unavailable` с причиной в `channels.reasons.vector`.
- **Часть 4a службы (очередь, запись).** `POST /review/items/{id}/resolve`: исход — ещё `partial` и `uncertain`, поле `confidence` (0–1) — их даёт модель, которая решает только пункты `semantic`; человек — `confirmed` или `refuted`. `ReviewItemView`: `current` и `proposed` — у `edit` и `imported` (`proposed.changes` — отличия от текущей), `versions` — у `source_changed`. `ReviewStats`: ещё `now`, `days`, `changesets`, `audit` (`verdicts` — итоги сверки источников). `GET /review/stats`: `days` до 36500. Тело `/submit` описано схемами `Proposal` (`target` — `atom` или `entity`; `record_id` — UUID правки или `null`) и `LinkProposal` (поля `LinkPayload` схемы v1: `rel`, `src`, `dst`, `note`, `qualifiers`, `confidence`), с примером. `Submitted.warnings` — предупреждения службы в форме `CheckIssue` (`private_removed`: скрытое в `<private>` вырезано); у 422 `check_rejected` — `issues` (у каждого `ref` — `@имя`, `proposals[i]` или `links[i]` — и `path` поля), `changeset_id` и `warnings`. Тело записи — не больше 1 МиБ (413 `too_large`). Папки создаёт, удаляет и переименовывает только человек (`person:`), модель — 403 `forbidden`; переносить запись (`PATCH /records/{ref}/folder`) вправе и модель.
- **Отказы по праву (403).** `forbidden` — действие только для человека: папки создаёт, удаляет и переименовывает `person:`; модель переносит запись только в существующую папку (иначе 404 `folder_not_found`). `review_forbidden` — очередь: модель решает только `semantic` и не свой пакет, пункт вручную ставит человек, захваченный другим пункт не решить. `read_only` — токен без права записи. Ключ тела с меткой `<private>` — 400 (скрытое в имени поля не вырезать); `note` у `resolve` и `enqueue` — после `private.strip`; `report` ответа `/submit` — с метками `proposals[i]`/`links[i]`, как в `records` и 422.
